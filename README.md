# Airbnb-inspired UI clone

A mobile-first Next.js 16 prototype with an explore page, a searchable catalog,
and listing details. It uses the App Router, React, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use `npm run lint` and
`npm run build` to check the project.

Listings, reviews, and maps are illustrative. Search and favorites are kept in
memory while navigating; no account, payment, or booking is created. Listing
photographs are loaded from Unsplash and require an internet connection.
